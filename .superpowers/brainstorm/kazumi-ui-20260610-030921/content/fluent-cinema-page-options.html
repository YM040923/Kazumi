Fluent Cinema Shell - Phase 1

首页 + 详情页 + 播放入口：选择第一阶段气质

三套方案都围绕 Windows 影视客户端感。区别是：第一眼更沉浸、日常找番更高效，还是观看链路更短。

推荐

A1. Cinematic Discover

首页先做大视觉冲击：featured、继续观看、热门与新番横排。详情页保持封面背景，播放入口更突出。

A2. Search-led Desktop

搜索和筛选成为桌面首页核心。更像 Plex Discover，找番效率强，但首页影视感会比 A1 克制。

A3. Episode-first Theater

详情页和选集/源选择最优先，播放入口最短。适合“点开就看”，但首页发现感和品牌感弱一些。

我建议选 A1 作为第一阶段：它最能给 Kazumi 带来“这不是普通 Flutter 网格页，而是一个现代影视客户端”的第一眼变化；A2/A3 的效率组件可以在 A1 内逐步吸收。
